# MCP ElevenLabs Speech Server

The full, maintained documentation for this server (tools, parameters,
environment variables, run modes, output formats, presets, limitations) lives
in the crate README: [../README.md](../README.md).

Quick reference:

| Tool | Purpose | Needs API key |
|------|---------|---------------|
| `synthesize_speech` | Text-to-speech, saved to a local audio file | yes |
| `generate_sound_effect` | Sound effect from a text prompt (0.5-30 s) | yes |
| `list_voices` | Account voices, with search/category filters | yes |
| `get_user_subscription` | Tier and character usage | yes |
| `get_models` | Available models and limits | yes |
| `list_presets` | Built-in voice settings presets | no |
| `clear_cache` | Delete audio files generated by this server | no |

When running in HTTP mode (`--mode standalone`, port 8018 in docker-compose):

- `GET /health` - health check
- `GET /mcp/tools` - list tools
- `POST /mcp/execute` - execute a tool (`{"tool": "...", "arguments": {...}}`)
- `POST /messages` - MCP JSON-RPC endpoint
